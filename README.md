# Single-Cycle Processor (Verilog)

This repository contains the Verilog implementation of core components for a **single-cycle processor**, developed as part of a class project.  
The goal is to design and integrate the fundamental building blocks used in a single-cycle CPU datapath.

## Files in this Repository

### `ALU.v`
Implements the **Arithmetic Logic Unit (ALU)**.  
Responsible for performing arithmetic and logical operations such as:
- Addition
- Subtraction
- Logical AND / OR
- Comparison operations (as required)

The ALU operation is selected based on control signals generated by the decoder.

### `Decoder.v`
Implements the **instruction decoder and control unit**.  
This module:
- Decodes instruction fields (e.g., opcode, funct)
- Generates control signals for the datapath
- Determines ALU control signals, register write enables, etc.

### `register.v`
Implements the **register file**.  
Supports:
- Reading from source registers
- Writing to destination registers
- Synchronous write and combinational read behavior (as specified by the design)

## Tools & Language
- **Language:** Verilog HDL
  
## Notes
- This is a **single-cycle** design: each instruction completes in one clock cycle.
